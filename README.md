# QuickKey downloads

Official macOS and Windows builds for the QuickKey macro deck.

## Latest version

- [Download for macOS (Apple silicon and Intel)](https://github.com/dushyantgithub/quickkey-releases/releases/latest/download/QuickKey-latest-mac.zip)
- [Download for Windows 10 and 11](https://github.com/dushyantgithub/quickkey-releases/releases/latest/download/QuickKey-latest-windows.exe)

Each build is created automatically from the private QuickKey source repository. Versioned files are retained so a specific release can always be downloaded again.
